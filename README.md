# Mohamed Shibil Vadakkan — Geoscience Portfolio

A React, TypeScript, Vite, and Tailwind CSS portfolio exploring the intersection of geology and technology.

## Prerequisites

Install the current Node.js LTS release from [nodejs.org](https://nodejs.org/). npm is included with Node.js; it is not installed separately.

On Windows, after installing Node.js, close and reopen PowerShell or the VS Code terminal so the updated `PATH` is loaded. Verify both commands are available:

```powershell
node --version
npm --version
```

If either command is still not recognized, restart VS Code (or Windows) and check that the Node.js installation directory is on `PATH`.

## Development

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.
